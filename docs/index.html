Built for long listening sessions

Everything runs locally against your ~/Music folder with zero cloud accounts or tracking

01 · Streaming & resume

Instant seeking inside 100+ minute MP3 sets

Localify serves files from a session-authenticated HTTP 206 Partial Content server on 127.0.0.1 and persists playback position for long sets so you pick up right where you paused.

GET /media/:token/:id
Range: bytes=0-65535
206 Partial Content
Accept-Ranges: bytes
Chapter markers + MediaSession keys
02 · Archiver

Built-in yt-dlp queue

Paste links or import links.txt, extract MP3, M4A, or OPUS with embedded artwork and chapters, and guard radio links with --no-playlist.

03 · Library

Fast ffprobe scanner

Indexes audio metadata, bitrate, duration, and embedded thumbnails across ~/Music while preserving likes, playlists, and resume positions.

04 · Desktop

Linux keyboard & dock ready

Supports Space, arrow seeking, Ctrl+F search, Ctrl+D downloader jump, Ubuntu hardware media keys, and one-command GNOME dock pinning.

Run it locally

Requires Node.js 20+, yt-dlp, ffmpeg, and ffprobe on Linux

bash 
git clone https://github.com/Darkside0908/localify.git
cd localify
npm install
npm run build
./launch.sh

# Optional: add Localify to your Ubuntu app menu
./install-desktop-entry.sh
